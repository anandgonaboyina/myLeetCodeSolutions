<h2><a href="https://takeuforward.org/plus/">Find the intersection point of Y LL</a></h2><h3>Medium</h3><hr><p>Given the heads<strong> </strong>of two linked lists A and B, containing positive integers. Find the node at which the two linked lists <strong>intersect</strong>. If they do intersect, return the node<strong> </strong>at which the intersection begins, otherwise return null.</p><p><br></p><p>The Linked List will not<strong> </strong>contain any cycles. The linked lists must retain<strong> </strong>their original<strong> </strong>structure, given as per the input, after<strong> </strong>the function returns.</p><p><br></p><p><strong>Note</strong>: for custom input, the following parameters are required(your program is not<strong> </strong>provided with these parameters):</p><ul><li><strong>intersectVal </strong>- The value of the node where the intersection occurs. This is -1 if there is no intersected node.</li><li><strong>skipA </strong>- The number of nodes to skip ahead in listA (starting from the head) to get to the intersected node(<strong>-1</strong> if no intersection).</li><li><strong>skipB </strong>- The number of nodes to skip ahead in listB (starting from the head) to get to the intersected node(<strong>-1</strong> if no intersection).</li><li><strong>listA </strong>- The first linked list.</li><li><strong>listB </strong>- The second linked list.</li></ul><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: listA: intersectVal = 4, skipA = 3, skipB = 2, head -&gt; 1 -&gt; 2 -&gt; 3 -&gt; 4 -&gt; 5, listB: head -&gt; 7 -&gt; 8 -&gt; 4 -&gt; 5</p><p><img src="https://static.takeuforward.org/content/ProblemSetter-9Sg1d-Lo"></p><p><strong>Output</strong>(value at returned node is displayed): 4</p><p><strong>Explanation</strong>: The two lists have nodes with values 4 and 5 as their tails.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: listA: intersectVal = -1, skipA = -1, skipB = -1, head -&gt; 1 -&gt; 2 -&gt; 3, listB: head -&gt; 8 -&gt; 9</p><p><img src="https://static.takeuforward.org/content/ProblemSetter-p32uBGcT"></p><p><strong>Output</strong>(value at returned node is displayed): null</p><p><strong>Explanation</strong>: The two lists do not intersect.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>m == number of nodes in listA.</li><li>n == number of nodes in listB.</li><li>1 &lt;= m, n &lt;= 5 * 10<sup>4</sup></li><li>0 &lt;= ListNode.val &lt;= 10<sup>4</sup></li><li>0 &lt;= skipA &lt; m</li><li>0 &lt;= skipB &lt; n</li><li>intersectVal, skipA, skipB is -1 if listA and listB do not intersect.</li><li>intersectVal == listA[skipA] == listB[skipB] if listA and listB intersect.</li></ul></div><br><br>
