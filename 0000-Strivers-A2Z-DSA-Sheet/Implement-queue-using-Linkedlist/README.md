<h2><a href="https://takeuforward.org/plus/">Implement queue using Linkedlist</a></h2><h3>Medium</h3><hr><p>Implement a First-In-First-Out (FIFO) queue using a singly linked list. The implemented queue should support the following operations: push, pop, peek, and isEmpty.</p><p><br></p><p>Implement the LinkedListQueue class:</p><p><br></p><p>void push(int x): Adds element x to the end of the queue.</p><p>int pop(): Removes and returns the front element of the queue.</p><p>int peek(): Returns the front element of the queue without removing it.</p><p>boolean isEmpty(): Returns true if the queue is empty, false otherwise.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p>Input:</p><p>["LinkedListQueue", "push", "push", "peek", "pop", "isEmpty"]</p><p>[[], [3], [7], [], [], []]</p><p>Output:[null, null, null, 3, 3, false]</p><p>Explanation:</p><p>LinkedListQueue queue = new LinkedListQueue();</p><p>queue.push(3);</p><p>queue.push(7);</p><p>queue.peek(); // returns 3</p><p>queue.pop(); // returns 3</p><p>queue.isEmpty(); // returns false</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p>Input:</p><p>["LinkedListQueue", "push", "pop", "isEmpty"]</p><p>[[], [2], [], []]</p><p>Output: [null, null, 2, true]</p><p>Explanation:</p><p>LinkedListQueue queue = new LinkedListQueue();</p><p>queue.push(2);</p><p>queue.pop(); // returns 2</p><p>queue.isEmpty(); // returns true</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= numbers of calls made &lt;= 100</li><li>1 &lt;= x &lt;= 100</li></ul></div><br><br>
