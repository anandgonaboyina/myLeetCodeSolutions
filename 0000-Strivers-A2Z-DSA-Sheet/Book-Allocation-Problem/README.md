<h2><a href="https://takeuforward.org/plus/">Book Allocation Problem</a></h2><h3>Medium</h3><hr><p>Given an array nums of n integers, where nums[i] represents the number of pages in the i-th book, and an integer m representing the number of students, allocate all the books to the students so that each student gets at least one book, each book is allocated to only one student, and the allocation is contiguous.</p><p><br></p><p>Allocate the books to m students in such a way that the <strong>maximum number of pages</strong> assigned to a student is minimized. If the allocation of books is not possible, return -1.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p>Input: nums = [12, 34, 67, 90], m=2</p><p>Output: 113</p><p>Explanation: The allocation of books will be 12, 34, 67 | 90. One student will get the first 3 books and the other will get the last one.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p>Input:&nbsp;nums = [25, 46, 28, 49, 24], m=4</p><p>Output: 71</p><p>Explanation: The allocation of books will be 25, 46 | 28 | 49 | 24.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>&nbsp;&nbsp;1 &lt;= n, m &lt;= 10<sup>4</sup></li><li>&nbsp;&nbsp;1 &lt;= nums[i] &lt;= 10<sup>5</sup></li></ul></div><br><br>
