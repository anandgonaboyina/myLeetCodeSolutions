<h2><a href="https://takeuforward.org/plus/">Reverse every word in a string</a></h2><h3>Medium</h3><hr><p>Given an input string, containing upper-case and lower-case letters, digits, and spaces( ' ' ). A word is defined as a sequence of non-space characters. The words in s are separated by at least one space.</p><p><br></p><p>Return a string with the words in <strong>reverse order</strong>, concatenated by a single space.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p>Input: s = "welcome to the jungle"</p><p><br></p><p>Output: "jungle the to welcome"</p><p><br></p><p>Explanation: The words in the input string are "welcome", "to", "the", and "jungle". Reversing the order of these words gives "jungle", "the", "to", and "welcome". The output string should have exactly one space between each word.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p>Input: s = " amazing coding skills "</p><p><br></p><p>Output: "skills coding amazing"</p><p><br></p><p>Explanation: The input string has leading and trailing spaces, as well as multiple spaces between the words "amazing", "coding", and "skills". After trimming the leading and trailing spaces and reducing the multiple spaces between words to a single space, the words are "amazing", "coding", and "skills". Reversing the order of these words gives "skills", "coding", and "amazing". The output string should not have any leading or trailing spaces and should have exactly one space between each word.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= s.length &lt;= 10<sup>4</sup></li><li>s contains English letters (upper-case and lower-case), digits, and spaces ' '.</li><li>There is at least one word in s.</li></ul></div><br><br>
