<h2><a href="https://takeuforward.org/plus/">Find Middle of Linked List</a></h2><h3>Medium</h3><hr><p>Given the <strong>head </strong>of a singly Linked List, return the <strong>middle </strong>node of the Linked List.</p><p><br></p><p>If the Linked List has an <strong>even </strong>number of nodes, return the <strong>second </strong>middle one.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 3 -&gt; 8 -&gt; 7 -&gt; 1 -&gt; 3</p><p><strong>Output</strong>(value at returned node): 7</p><p><strong>Explanation</strong>: There are 5 nodes, so the middle node is the 3<sup>rd</sup> Node, with value 7.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 2 -&gt; 9 -&gt; 1 -&gt; 4 -&gt; 0 -&gt; 4</p><p><strong>Output</strong>(value at returned node): 4</p><p><strong>Explanation</strong>: There are 6 nodes, thus both the 3<sup>rd</sup> and 4<sup>th</sup> nodes are middle. So the 2<sup>nd</sup> middle node (4<sup>th</sup> Node) is returned with value 4.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><p>1 &lt;= number of Nodes in the Linked List &lt;= 10<sup>5</sup></p><p>-10<sup>4</sup> &lt;= ListNode.val &lt;= 10<sup>4</sup></p></div><br><br>
