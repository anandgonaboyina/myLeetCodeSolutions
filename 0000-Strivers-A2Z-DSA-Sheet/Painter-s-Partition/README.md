<h2><a href="https://takeuforward.org/plus/">Painter's Partition</a></h2><h3>Medium</h3><hr><p>You are given <strong>A</strong> painters and an array <strong>C </strong>of <strong>N </strong>integers where<strong> C[i] </strong>denotes the length of the<strong> i</strong><sup><strong>th</strong></sup> board. Each painter takes <strong>B</strong> units of time to paint 1 unit of board. You must assign boards to painters such that:</p><ul><li>Each painter paints only <strong>contiguous</strong> segments of boards.</li><li>No board can be <strong>split between painters</strong>.</li><li>The goal is to <strong>minimize</strong> the <strong>time </strong>to paint all boards.</li></ul><p><br></p><p>Return the minimum time required to paint all boards <strong>modulo 10000003</strong>.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input:</strong> A = 2, B = 5, C = [1, 10]</p><p><strong>Output: </strong>50</p><p><strong>Explanation:</strong></p><ul><li>Painter 1 paints board 0 (length = 1), time = 5</li><li>Painter 2 paints board 1 (length = 10), time = 50</li><li>Max time = 50</li><li>Return 50 % 10000003 = 50</li></ul></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input:</strong> A = 10, B = 1, C = [1, 8, 11, 3]</p><p><strong>Output: </strong>11</p><p><strong>Explanation:</strong></p><ul><li>Assign each board to a different painter</li><li>Max time = max(1, 8, 11, 3) = 11</li><li>Return 11 % 10000003 = 11</li></ul></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= A &lt;= 1000</li><li>1 &lt;= B &lt;= 10<sup>6</sup></li><li>1 &lt;= N &lt;= 10<sup>5</sup></li><li>1 &lt;= C[i] &lt;= 10<sup>6</sup></li></ul></div><br><br>
