<h2><a href="https://takeuforward.org/plus/">Delete all occurrences of a key in DLL</a></h2><h3>Medium</h3><hr><p>Given the head of a doubly linked list and an integer target. <strong>Delete</strong> all nodes in the linked list with the value <strong>target </strong>and return the head of the modified linked list.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p>Input: head -&gt; 1 &lt;-&gt; 2 &lt;-&gt; 3 &lt;-&gt; 1 &lt;-&gt; 4, target = 1</p><p>Output: head -&gt; 2 &lt;-&gt; 3 &lt;-&gt; 4</p><p>Explanation: All nodes with the value 1 were removed.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p>Input: head -&gt; 2 &lt;-&gt; 3 &lt;-&gt; -1 &lt;-&gt; 4 &lt;-&gt; 2, target = 2</p><p>Output: head -&gt; 3 &lt;-&gt; -1 &lt;-&gt; 4</p><p>Explanation: All nodes with the value 2 were removed.</p><p>Note that the value of head is changed.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>0 &lt;= number of nodes in the linked list &lt;= 10<sup>5</sup></li><li>-10<sup>4</sup> &lt;= ListNode.val &lt;= 10<sup>4</sup></li><li>-10<sup>4</sup> &lt;= target &lt;= 10<sup>4</sup></li></ul></div><br><br>
