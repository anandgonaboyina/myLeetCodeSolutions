<h2><a href="https://takeuforward.org/plus/">Subsets I</a></h2><h3>Medium</h3><hr><p>Given an array nums of n integers. Return array of <strong>sum</strong> of all subsets of the array nums.</p><p><br></p><p>Output can be returned in any order.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input : </strong>nums = [2, 3]</p><p><strong>Output : </strong>[0, 2, 3, 5]</p><p><strong>Explanation : </strong></p><p>When no elements is taken then Sum = 0.</p><p>When only 2 is taken then Sum = 2.</p><p>When only 3 is taken then Sum = 3.</p><p>When element 2 and 3 are taken then&nbsp;sum = 2+3 = 5.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> nums = [5, 2, 1]</p><p><strong>Output :</strong> [0, 1, 2, 3, 5, 6, 7, 8]</p><p><strong>Explanation :</strong></p><p>When no elements is taken then Sum = 0.</p><p>When only 5 is taken then Sum = 5.</p><p>When only 2 is taken then Sum = 2.</p><p>When only 1 is taken then Sum = 1.</p><p>When element 2 and 1 are taken then&nbsp;sum = 2+1 = 3.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= n &lt;= 15</li><li>0 &lt;= nums[i] &lt;= 10<sup>4</sup></li></ul></div><br><br>
