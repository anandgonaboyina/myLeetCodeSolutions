Identify and return the two integers that appear only <strong>once</strong> in the array. Return the two numbers in <strong>ascending order</strong>.</p><p><br></p><p>For example, if nums = [1, 2, 1, 3, 5, 2], the correct answer is [3, 5], not [5, 3].</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> nums = [1, 2, 1, 3, 5, 2]</p><p><strong>Output :</strong> [3, 5]</p><p><strong>Explanation :</strong> The integers 3 and 5 have appeared only once.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> nums = [-1, 0]</p><p><strong>Output :</strong> [-1, 0]</p><p><strong>Explanation :</strong> The integers -1 and 0 have appeared only once.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>2 &lt;= nums.length &lt;= 10<sup>5</sup></li><li>-3*10<sup>5</sup> &lt;= nums[i] &lt;= 3*10<sup>5</sup></li><li>Every integer in <strong>nums</strong> appears twice except two integers.</li></ul></div><br><br>
