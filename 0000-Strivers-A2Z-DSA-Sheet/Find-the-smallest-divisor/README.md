<h2><a href="https://takeuforward.org/plus/">Find the smallest divisor</a></h2><h3>Medium</h3><hr><p>Given an array of integers nums and an integer limit as the threshold value, find the <strong>smallest positive integer divisor</strong> such that upon dividing all the elements of the array by this divisor, the sum of the division results is less than or equal to the threshold value.</p><p>After dividing each element by the chosen divisor, take the <strong>ceiling </strong>of the result <strong>(i.e., round up to the next whole number)</strong>.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p>Input: nums = [1, 2, 3, 4, 5], limit = 8</p><p>Output: 3</p><p>Explanation: We can get a sum of 15(1 + 2 + 3 + 4 + 5) if we choose 1 as a divisor.&nbsp;</p><p>The sum is 9(1 + 1 + 2 + 2 + 3)&nbsp;if we choose 2 as a divisor. Upon dividing all the elements of the array by 3, we get 1,1,1,2,2 respectively. Now, their sum is equal to 7 &lt;= 8 i.e. the threshold value. So, 3 is the minimum possible answer.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p>Input: nums = [8,4,2,3], limit = 10</p><p>Output: 2</p><p>Explanation: If we choose 1, we get 17 as the sum. If we choose 2, we get 9 (4+2+1+2) &lt;= 10 as the answer. So, 2 is the answer.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= nums.length &lt;= 5 * 10<sup>4</sup></li><li>&nbsp;1 &lt;= nums[i] &lt;= 10<sup>6</sup></li><li>&nbsp;nums.length &lt;= limit &lt;= 10<sup>6</sup></li></ul></div><br><br>
