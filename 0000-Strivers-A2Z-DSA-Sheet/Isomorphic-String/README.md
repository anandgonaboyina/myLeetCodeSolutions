<h2><a href="https://takeuforward.org/plus/">Isomorphic String</a></h2><h3>Medium</h3><hr><p>Given two strings <strong>s</strong> and <strong>t</strong>, determine if they are <strong>isomorphic</strong>. Two strings s and t are <strong>isomorphic</strong> if the characters in s can be replaced to get t.</p><p><br></p><p>All occurrences of a character must be replaced with another character while preserving the order of characters. No two characters may map to the same character, but a character may map to itself.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> s = "egg" , t = "add"</p><p><strong>Output :</strong> true</p><p><strong>Explanation :</strong></p><p>The 'e' in string s can be replaced with 'a' of string t.</p><p>The 'g' in string s can be replaced with 'd' of t.</p><p>Hence all characters in s can be replaced to get t.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> s = "apple" , t = "bbnbm"</p><p><strong>Output :</strong> false</p><p><strong>Explanation : </strong></p><p>Strings are matched <strong>index by index</strong>.</p><p>At index 0, 'a' maps to 'b'.</p><p> At index 1, 'p' also maps to 'b'.</p><p>This is invalid because <strong>two different characters (a and p) cannot map to the same character (b)</strong> in a one-to-one mapping.</p><p>Therefore, no valid mapping exists and the output is false.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= s.length &lt;= 10<sup>3</sup></li><li>s.length == t.length</li><li>s and t consist of only lowercase English letters.</li></ul></div><br><br>
