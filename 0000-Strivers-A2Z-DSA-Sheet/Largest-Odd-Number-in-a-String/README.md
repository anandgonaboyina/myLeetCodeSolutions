<h2><a href="https://takeuforward.org/plus/">Largest Odd Number in a String</a></h2><h3>Medium</h3><hr><p>Given a string <strong>s</strong>, representing a large integer, the task is to return the largest-valued <strong>odd</strong> <strong>integer</strong> (as a string) that is a <strong>substring</strong> of the given string s.</p><p><br></p><p>The number returned should <strong>not</strong> have leading <strong>zero's</strong>. But the given input string may have leading zero. (If no odd number is found, then return empty string.)</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> s = "5347"</p><p><strong>Output :</strong> "5347"</p><p><strong>Explanation :</strong> </p><p>The odd numbers formed by given strings are --&gt; 5, 3, 53, 347, 5347.</p><p>So the largest among all the possible odd numbers for given string is 5347.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> s = "0214638"</p><p><strong>Output :</strong> "21463"</p><p><strong>Explanation :</strong> </p><p>The different odd numbers that can be formed by the given string are --&gt; 1, 3, 21, 63, 463, 1463, 21463.</p><p>We cannot include 021463 as the number contains leading zero.</p><p>So largest odd number in given string is 21463.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= s.length &lt;= 10<sup>3</sup></li><li>'0' &lt;= s[i] &lt;= '9'</li></ul></div><br><br>
