<h2><a href="https://takeuforward.org/plus/">Segregate odd and even nodes in Linked List</a></h2><h3>Medium</h3><hr><p>Given the head of a singly linked list. Group all the nodes with <strong>odd indices</strong> followed by all the nodes with <strong>even indices</strong> and return the reordered list.</p><p><br></p><p>Consider the 1<sup>st</sup> node to have index 1 and so on. The relative order of the elements inside the odd and even group must remain the same as the given input.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: linkedList = [1, 2, 3, 4, 5]</p><p><strong>Output</strong>: [1, 3, 5, 2, 4]</p><p><strong>Explanation</strong>: </p><p>The nodes with odd indices are 1, 3, 5 and the ones with even indices are 2, 4.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: linkedList = [4, 3, 2, 1]</p><p><strong>Output</strong>: [4, 2, 3, 1]</p><p><strong>Explanation</strong>: </p><p>The nodes with odd indices are 4, 2 and the ones with even indices are 3, 1.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>0 &lt;= number of nodes in the Linked List &lt;= 10<sup>5</sup></li><li>0 &lt;= ListNode.val &lt;= 10<sup>4</sup></li></ul></div><br><br>
