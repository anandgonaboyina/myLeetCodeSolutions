<h2><a href="https://takeuforward.org/plus/">Delete the middle node in LL</a></h2><h3>Medium</h3><hr><p>Given the head of a non-empty singly linked list containing integers, <strong>delete</strong> the middle node of the linked list. Return the head of the modified linked list.</p><p><br></p><p>The middle node of a linked list of size n is the <strong>(⌊n / 2⌋ + 1)</strong><sup><strong>th</strong></sup><strong> </strong>node from the start using 1-based indexing, where ⌊x⌋ denotes the largest integer less than or equal to x.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 1 -&gt; 2 -&gt; 3 -&gt; 4 -&gt; 5</p><p><strong>Output</strong>: head -&gt; 1 -&gt; 2 -&gt; 4 -&gt; 5</p><p><strong>Explanation</strong>: n = 5.</p><p>⌊n / 2⌋ + 1 = 3, therefore middle node has index 3 and so the node with value 3 was deleted.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 7 -&gt; 6 -&gt; 5 -&gt; 4</p><p><strong>Output</strong>: head -&gt; 7 -&gt; 6 -&gt; 4</p><p><strong>Expl﻿anation</strong>: n = 4.</p><p>⌊n / 2⌋ + 1 = 3, therefore middle node has index 3 and so the node with value 5 was deleted.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= number of nodes in the Linked List &lt;= 10<sup>5</sup></li><li>0 &lt;= ListNode.val &lt;= 10<sup>4</sup></li></ul></div><br><br>
