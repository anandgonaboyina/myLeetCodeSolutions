<h2><a href="https://takeuforward.org/plus/">Find Peak Element - II</a></h2><h3>Medium</h3><hr><p>Given a 0-indexed n x m matrix mat where no two adjacent cells are equal, find any <strong>peak element</strong> mat[i][j] and return the <strong>array [i, j]</strong>.A peak element in a 2D grid is an element that is strictly greater than all of its adjacent neighbours to the left, right, top, and bottom.</p><p><br></p><p>Assume that the entire matrix is surrounded by an outer perimeter with the value -1 in each cell.</p><p><br></p><p>Note: As there can be many peak values, 1 is given as output if the returned index is a peak number, otherwise 0.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p>Input: mat=[[10, 20, 15], [21, 30, 14], [7, 16, 32]]</p><p>Output: [1, 1]</p><p>Explanation: The value at index [1, 1] is 30, which is a peak element because all its neighbours are smaller or equal to it. Similarly, {2, 2} can also be picked as a peak.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p>Input: mat=[[10, 7], [11, 17]]</p><p>Output : [1, 1]</p><p>Explanation:<span style="color: rgb(245, 245, 245);">The value at index [1, 1] is 17, which is the only peak element because all its neighbours are smaller or equal to it.</span></p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>&nbsp;&nbsp;n == mat.length</li><li>&nbsp;&nbsp;m == mat[i].length</li><li>&nbsp;&nbsp;1 &lt;= m, n &lt;= 500</li><li>&nbsp;&nbsp;1 &lt;= mat[i][j] &lt;= 10<sup>5</sup></li><li>&nbsp;&nbsp;No two adjacent cells are equal</li></ul></div><br><br>
