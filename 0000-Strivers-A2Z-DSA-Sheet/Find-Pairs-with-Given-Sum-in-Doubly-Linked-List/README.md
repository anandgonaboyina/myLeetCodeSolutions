The list is sorted in ascending order. If there are no such pairs, return an empty list.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input:</strong> head = [1, 2, 4, 5, 6, 8, 9], target = 7</p><p><strong>Output:</strong> [[1, 6], [2, 5]]</p><p><strong>Explanation:</strong></p><p>1 + 6 = 7 and 2 + 5 = 7 are the valid pairs.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input:</strong> head = [1, 5, 6], target = 6</p><p><strong>Output:</strong> [[1, 5]]</p><p><strong>Explanation:</strong></p><p>1 + 5 = 6 is the only valid pair.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>0 &lt;= number of nodes &lt;= 10<sup>5</sup></li><li>1 &lt;= Node.val &lt;= 10<sup>5</sup></li><li>1 &lt;= target &lt;= 10<sup>5</sup></li><li>The linked list is sorted in strictly increasing order</li><li>The linked list is contains distinct values</li></ul></div><br><br>
