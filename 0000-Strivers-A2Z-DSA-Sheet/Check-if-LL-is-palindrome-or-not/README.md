<h2><a href="https://takeuforward.org/plus/">Check if LL is palindrome or not</a></h2><h3>Medium</h3><hr><p>Given the head of a singly linked list representing a positive integer number. Each node of the linked list represents a digit of the number, with the 1st node containing the leftmost digit of the number and so on. Check whether the linked list values form a palindrome or not. Return true if it forms a palindrome, otherwise, return false.</p><p><br></p><p>A palindrome is a sequence that reads the same forward and backwards.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 3 -&gt; 7 -&gt; 5 -&gt; 7 -&gt; 3</p><p><strong>Output</strong>: true</p><p><strong>Explanation</strong>: 37573 is a palindrome.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 1 -&gt; 1 -&gt; 2 -&gt; 1</p><p><strong>Output</strong>: false</p><p><strong>Explanation</strong>: 1121 is not a palindrome.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= number of nodes in the Linked List &lt;= 10<sup>5</sup></li><li>0 &lt;= ListNode.val &lt;= 9</li><li>The number represented does not contain any leading zeroes.</li></ul></div><br><br>
