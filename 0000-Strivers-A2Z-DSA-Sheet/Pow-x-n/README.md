<h2><a href="https://takeuforward.org/plus/">Pow(x,n)</a></h2><h3>Medium</h3><hr><p>Implement the power function pow(x, n) , which calculates the x raised to n i.e. <strong>x</strong><sup><strong>n</strong></sup>.</p><p><br></p><p><strong>Note </strong>: In output print <strong>4 digits places</strong> after decimal point.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> x = 2.0000 , n = 10</p><p><strong>Output :</strong> 1024.0000</p><p><strong>Explanation :</strong> Answer = 2^10 =&gt; 1024.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> x = 2.0000 , n = -2</p><p><strong>Output :</strong> 0.2500</p><p><strong>Explanation :</strong> Answer = 2^(-2) = 1/4 =&gt; 0.25.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>-100.0 &lt;= x &lt;= 100.0</li><li>-2<sup>31</sup> &lt;= n &lt;= 2<sup>31</sup> - 1</li><li>-10<sup>4</sup> &lt;= x<sup>n </sup>&lt;= 10<sup>4</sup></li><li>Either x is not zero or n&gt;0.</li><li>n is an integer.</li></ul></div><br><br>
