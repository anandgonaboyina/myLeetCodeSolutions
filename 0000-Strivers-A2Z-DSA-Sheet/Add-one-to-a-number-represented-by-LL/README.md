<h2><a href="https://takeuforward.org/plus/">Add one to a number represented by LL</a></h2><h3>Medium</h3><hr><p>Given the <strong>head </strong>of a singly linked list representing a positive <strong>integer </strong>number. <strong>Each </strong>node of the linked list represents a <strong>digit </strong>of the number, with the 1st node containing the leftmost digit of the number and so on. The task is to <strong>add one</strong> to the value represented by the linked list and <strong>return </strong>the head of a linked list containing the final value.</p><p><br></p><p>The number will contain <strong>no </strong>leading zeroes except when the value represented is <strong>zero </strong>itself.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 1 -&gt; 2 -&gt; 3</p><p><strong>Output</strong>: head -&gt; 1 -&gt; 2 -&gt; 4</p><p><strong>Explanation</strong>: The number represented by the linked list = 123.</p><p>123 + 1 = 124.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input</strong>: head -&gt; 9 -&gt; 9</p><p><strong>Output</strong>: head -&gt; 1 -&gt; 0 -&gt; 0</p><p><strong>Explanation</strong>: The number represented by the linked list = 99.</p><p>99 + 1 = 100.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>0 &lt;= number of nodes in the Linked List &lt;= 10<sup>5</sup></li><li>0 &lt;= ListNode.val &lt;= 9</li><li>No leading zeroes in the value represented.</li></ul></div><br><br>
