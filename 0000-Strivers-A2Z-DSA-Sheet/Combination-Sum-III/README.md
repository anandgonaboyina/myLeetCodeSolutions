<h2><a href="https://takeuforward.org/plus/">Combination Sum III</a></h2><h3>Medium</h3><hr><p>Determine all possible set of k numbers that can be added together to equal n while meeting the following requirements:</p><p><br></p><ul><li class="ql-indent-1">There is only use of numerals 1 through 9.</li><li class="ql-indent-1">A single use is made of each number.</li></ul><p><br></p><p>Return list of every <strong>feasible combination</strong> that is allowed. The combinations can be returned in any order, but the list cannot have the same combination twice.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> k = 3 , n = 7</p><p><strong>Output :</strong> [ [1, 2, 4] ]</p><p><strong>Explanation :</strong></p><p>1 + 2 + 4 = 7</p><p>There are no other valid combinations.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> k = 3, n = 9</p><p><strong>Output :</strong> [[1, 2, 6],[1, 3, 5],[2, 3, 4]]</p><p><strong>Explanation :</strong></p><p>1 + 2 + 6 = 9</p><p>1 + 3 + 5 = 9</p><p>2 + 3 + 4 = 9</p><p>There are no other valid combinations.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>2 &lt;= k &lt;= 9</li><li>1 &lt;= n &lt;= 60</li></ul></div><br><br>
