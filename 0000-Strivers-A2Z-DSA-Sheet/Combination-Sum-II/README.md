<h2><a href="https://takeuforward.org/plus/">Combination Sum II</a></h2><h3>Medium</h3><hr><p>Given collection of candidate numbers (candidates) and a integer target<em>.</em>Find all <strong>unique combinations</strong> in candidates where the sum is equal to the target.There can only be <strong>one</strong> <strong>usage</strong> of each number in the candidates combination and return the answer in <strong>sorted</strong> order.</p><p><br></p><p>e.g : The combination [1, 1, 2] and [1, 2, 1] are not unique.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> candidates = [2, 1, 2, 7, 6, 1, 5] , target = 8</p><p><strong>Output :</strong>&nbsp;[ [1, 1, 6] , [1, 2, 5] , [1, 7] , [2, 6] ]</p><p><strong>Explanation :</strong> The combinations sum up to target are</p><p>1 + 1 + 6 =&gt; 8.</p><p>1 + 2 + 5 =&gt; 8.</p><p>1 + 7 =&gt; 8.</p><p>2 + 6 =&gt; 8.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><strong>Input :</strong> candidates = [2, 5, 2, 1, 2] , target = 5</p><p><strong>Output :</strong>&nbsp;[ [1, 2, 2] , [5] ]</p><p><strong>Explanation :</strong> The combinations sum up to target are</p><p>1 + 2 + 2 =&gt; 5.</p><p>5 =&gt; 5.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>1 &lt;= candidates.length &lt;= 100</li><li>1 &lt;= candidates[i] &lt;= 50</li><li>1 &lt;= target &lt;= 30</li></ul></div><br><br>
