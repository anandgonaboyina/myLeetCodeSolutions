<h2><a href="https://takeuforward.org/plus/">Length of loop in LL</a></h2><h3>Medium</h3><hr><p>Given the head of a singly linked list, find the length of the loop in the linked list if it exists. Return the length of the loop if it exists; otherwise, return 0.</p><p><br></p><p>A loop exists in a linked list if some node in the list can be reached again by continuously following the next pointer. Internally, pos is used to denote the index (0-based) of the node from where the loop starts.</p><p><br></p><p>Note that pos is not passed as a parameter.</p><br><br><p class="tuf-text-14">Example 1</p><div class="tuf-example text-new_secondary"><p><img src="https://static.takeuforward.org/content/ProblemSetter-50ZbpwmN"></p><p><strong>Input</strong>: head -&gt; 1 -&gt; 2 -&gt; 3 -&gt; 4 -&gt; 5, pos = 1</p><p><strong>Output</strong>: 4</p><p><strong>Explanation</strong>: 2 -&gt; 3 -&gt; 4 -&gt; 5 - &gt;2, length of loop = 4.</p></div><br><br><p class="tuf-text-14 ">Example 2</p><div class="tuf-example text-new_secondary"><p><img src="https://static.takeuforward.org/content/ProblemSetter-XbyBOQuP"></p><p><strong>Input</strong>: head -&gt; 1 -&gt; 3 -&gt; 7 -&gt; 4, pos = -1</p><p><strong>Output</strong>: 0</p><p><strong>Explanation</strong>: No loop is present in the linked list.</p></div><br><br><p class="tuf-text-14 ">Constraints</p><div class="tuf-dark-content-box"><ul><li>0 &lt;= number of nodes in the cycle &lt;= 10<sup>5</sup></li><li>0 &lt;= ListNode.val &lt;= 10<sup>4</sup></li><li>pos is -1 or a valid index in the linked list</li></ul></div><br><br>
